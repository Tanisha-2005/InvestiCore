## ⚡ Super-Quick 60-Second Launch Guide

If you just want to run the project immediately:

### 1️⃣ Start the Backend (Port 5000)
```bash
cd backend
npm install
npm start
```
> **Note**: If local MongoDB is not running, InvestiCore automatically spins up an **In-Memory MongoDB server**. Zero database setup required!

### 2️⃣ Start the Frontend (Port 3000)
Open a new terminal window:
```bash
cd frontend
npm install
npm run dev
```

### 3️⃣ Open Your Browser
Navigate to **[http://localhost:3000](http://localhost:3000)** and log in or register a new investigator account!
